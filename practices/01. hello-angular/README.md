# Hello Angular
Welcome to the first practice exercise of the course. In this exercise, we will set up a basic Angular application and explore its structure.

## The files structure
Under the `src/app` folder, you will find the file `app.html`. Open it and you will see the html structure that you also see on the browser when you run the application. 

Let's change it a little

Replace the content of the `<h1>` tag with the following text:

```html
<h1>Hello Angular</h1>
``` 

When you save it you will see that it also changed in the browser.
